# 11: pi-composer: edit inline and fenced code

**What to build:** Read and edit code inside the draft while preserving its contents and contextual Enter behavior.

**Blocked by:** 09: pi-composer: edit formatted prose and source.

**Status:** in-progress

- [ ] Inline and fenced code have readable live presentation while their complete contents remain editable.
- [ ] Preserve indentation, whitespace, delimiters, and example text when editing, wrapping, or changing views.
- [ ] Enter within fenced code continues the block; Shift+Enter inserts a newline and Cmd+Enter submits explicitly.
- [ ] Code examples containing file/skill-like text remain ordinary source for editing; formatting does not create hidden references.
- [ ] Selection replacement and undo/redo restore accurate code contents.
- [ ] Use public Pi highlighting/rendering services and verify exported source, visible output, and Enter behavior through the host boundary and Ghostty.
