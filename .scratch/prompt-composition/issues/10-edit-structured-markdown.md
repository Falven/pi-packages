# 10: pi-composer: edit lists, quotes, and rules

**What to build:** Edit structured Markdown and continue lists without accidentally submitting the draft.

**Blocked by:** 09: pi-composer: edit formatted prose and source.

**Status:** in-progress

- [ ] Quotes, lists, task lists, and horizontal rules display their structure while their source remains editable.
- [ ] Nested and wrapped structures preserve correct caret/selection mapping and surrounding Markdown.

- [ ] Structural edits and source-view changes share existing undo history and preserve constructs outside the formatted subset.
- [ ] Verify user-visible structured editing and Enter behavior through the public Pi boundary and real Ghostty.
