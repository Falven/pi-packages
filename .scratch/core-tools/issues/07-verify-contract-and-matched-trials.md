## Difference classification

- **Resolved implementation mismatches:** initial namespace-free replies lost ownership during replay, producing a function call with a JSON wrapper and a collapsed text result. Public assistant-message ownership receipts repaired that at `652266a`; its smoke and suite preserve raw custom calls and text boundaries. The suite then exposed a one-part array where the reference used a string for an empty yielded frame. The narrow `c2adc1b` repair preserves that string while retaining multiple processed parts. Its final smoke and continuation audit passed. Original failing shapes remain inspectable at their original revisions.
- **Verified remaining mismatch — image detail:** native image conversion emits `detail: "auto"` even when high or original detail was requested. The helper and local-image result preserve the requested value. This model-bound detail mismatch remains separate from the approved resizing constraint; no provider bypass repairs it.
- **Approved image-processing difference:** the frozen image operation returns an `application/octet-stream` data URL. In both live image repetitions, the reference sent text then a 625-byte RGB PNG; Pi's normal processing sent text, a 694-byte RGBA PNG, and a conversion notice. The image remained 240 by 80 with identical decoded RGB pixels. The reference omitted detail while Pi sent automatic detail. Encoded bytes, content-part count, and the appended notice therefore differ. These actual model-bound differences are retained, rather than stripping native processing to manufacture equality.
- **Approved host constraints:** effective selection, shell/image settings, interception and redaction, image normalization, session lifetime, native child-call identity/context after a yield, and safe-boundary notification delivery remain authoritative. Package activity identifiers do not repair native attribution. Explicit termination aborts pending host operations under the approved contract, unlike the observed reference command lifetime.
- **Assembly differences outside replacement scope:** full developer context, companion instructions and unrelated declarations, declaration placement, additional host input, and the common gateway namespace-description fallback remain native. Equal task prompts and forwarded controls do not imply equal entire requests. Reference replay includes an optional call status and separate output identifier that Pi omits; opaque IDs and timing also vary. These envelope differences do not change the inspected selected call inputs or processed result content.
- **Unverified behavior:** reference concurrent-wait arbitration and caller-only wait cancellation, exhaustive patch grammar and operating-system errors, extreme duration limits, malformed-image upstream acceptance, and image-helper combinations beyond the observed live case remain unverified. The simple text/image case now has literal model-bound ordering evidence; exhaustive cross-part parity is not claimed. Native automatic detail is a verified mismatch. The bundled core runtime comparison does not establish actual desktop-harness parity, immutable backend identity, deterministic outputs, general performance, or model superiority.

The bounded verification is complete with these limits. Full raw evidence remains outside the repository, and the approved specification, tickets, and normal observation indices contain the resulting status and evidence links.
