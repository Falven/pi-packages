# pi-paste

A paste policy extension scaffold for the [pi coding agent](https://pi.dev).

The package owns paste classification, inline/attachment decisions, and explicit overrides. It is designed for Pi's native editor as well as `pi-composer`. Its entry point is ready to load; feature behavior is not implemented yet, and the package is unpublished.

See the [specification](../../docs/specs/pi-paste.md), [ADRs](../../docs/specs/pi-paste.md#architecture-decisions), and [shared architecture](../../docs/architecture.md).

## Load the scaffold

From the repository root:

```bash
pi install ./packages/pi-paste
```
