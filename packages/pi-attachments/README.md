# pi-attachments

An attachment extension scaffold for the [pi coding agent](https://pi.dev).

The package owns snapshots, previews, restoration, retention, and delivery. It is designed for Pi's native editor as well as `pi-composer`. Its entry point is ready to load; feature behavior is not implemented yet, and the package is unpublished.

See the [specification](../../docs/specs/pi-attachments.md), [ADRs](../../docs/specs/pi-attachments.md#architecture-decisions), and [shared architecture](../../docs/architecture.md).

## Load the scaffold

From the repository root:

```bash
pi install ./packages/pi-attachments
```
