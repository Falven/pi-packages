# Preserve native clipboard identity

Native clipboard actions classify copied files and images through Pi's metadata, with file identity taking precedence over image data and configured handlers retaining their priority. The entire text paste is interpreted as one path, regardless of caret position or surrounding Markdown, with bare filenames resolved against the requesting working directory: a readable regular file enters the shared snapshot capture operation, while an unsuccessful match follows ordinary text-paste behavior silently. File capture uses the delivered paste without changing terminal bindings or rereading the clipboard. Ordinary edits to bare paths do not trigger capture, so removing an attachment reference's Markdown leaves its snapshot path as plain text; creating a valid local-file Markdown reference follows the capture lifecycle in [ADR 0007](0007-pi-attachments-retain-snapshots.md).
