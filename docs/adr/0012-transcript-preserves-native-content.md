# Chat presentation preserves native content

To keep independent Pi extensions composable, `pi-chat` reuses Pi's native rendering and extension contracts, with the isolated runtime adapter in [ADR 0022](0022-native-rows-in-an-owned-transcript.md) supplying exact native-row access and chat composition while Pi retains conversation and session ownership. Disclosure state and source references stay outside original message content, and Pi owns the conversation text rather than the package keeping a second history buffer. Editing Pi's source files, forking or replacing its client, or adding external apps or services is outside this design; capabilities that require a broader approach return to discussion rather than silently expanding that boundary.

## Consequences

Inspection of installed Pi 1.0.2 and source checkout 1.1.0 did not establish a complete implementation through public extension contracts. The accepted adapter borrows the actual native components, associates them with source occurrences during native construction, and owns the presentation layout; it preserves the effective renderer chain without text matching or a second set of active tool presenters.

The exception is necessary because [`custom()`](/Users/fran/Source/pi-packages/node_modules/@earendil-works/pi-coding-agent/dist/modes/interactive/interactive-mode.js:2282) occupies the editor area or overlays a still-rendered native chat view; public layout-root replacement supplies no native dock or restoration contract, and the live [renderer registries](/Users/fran/Source/pi-packages/node_modules/@earendil-works/pi-coding-agent/dist/core/extensions/runner.js:529) and complete [Markdown pipeline](/Users/fran/Source/pi-packages/node_modules/@earendil-works/pi-coding-agent/dist/modes/interactive/interactive-mode.js:1676) are not exposed through the extension context. Required capabilities determine whether the adapter can attach; no version allowlist is used. Real-host tests exercise Pi 1.0.2 and 1.1.0. Physical-terminal acceptance and performance measurements remain separate.
