# Record presentation relationships in native session entries

`pi-chat` may append minimal native custom session entries containing references and classifications needed to reconstruct reliably identified agent activity boundaries and final-response relationships. These entries stay outside model context, preserve original messages, and reference [Pi-owned content](0012-transcript-preserves-native-content.md) without copying conversation text. Manual disclosure choices remain in memory; metadata records established relationships and does not substitute for missing input-delivery or rendering identity.
