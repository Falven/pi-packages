# Resolve native editing actions before composer shortcuts

`pi-composer` resolves native editing actions through Pi's supplied keybinding manager and executes their ordinary source-text behavior against its authoritative draft, including Markdown characters hidden by formatted rendering, because the inherited editor maintains a separate text state. Native dispatch and effective bindings take priority over composer shortcuts, and any explicit override, including an empty binding list, suppresses aliases for that native action. Actions without native IDs use documented fixed shortcuts with the same priority rules, preserving Pi's existing customization contracts without introducing a separate configuration system.
