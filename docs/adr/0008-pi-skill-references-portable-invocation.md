# Skill invocation is portable text

`pi-skill-references` treats canonical `/skill:name` text in ordinary prose as explicit invocation whether typed, pasted, or inserted by another Pi extension; code examples follow the Markdown delivered after Pi's native submission trimming, so leading literal examples use fenced code. `$` and `/` completion triggers insert that native spelling, allowing native and custom pickers to use the same text interfaces and plain-text clipboard. Each referenced skill contributes its instructions once per submission.
