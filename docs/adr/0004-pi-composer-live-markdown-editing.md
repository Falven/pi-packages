# Live Markdown editing

`pi-composer` renders supported Markdown inside the editable draft, with a source view for direct syntax editing and local source reveal when deletion leaves part of a rendered element behind. In formatted view, character deletion without a selection edits the corresponding Markdown source character (`**bold**` becomes `**bold*` on Backspace at its end), while word, line, and selection deletion consumes the expected rendered text range and removes syntax belonging to fully deleted elements; deleting only part of an element, including one word from a multiword element, reveals its remaining source so users can see and edit the syntax. Both views share caret movement, selection, and undo, honor Pi's hardware-cursor setting, and render recognized link text with Pi's native hyperlinks, converting absolute local file destinations to file URLs; detailed editing rules are recorded in the [specification](../specs/pi-composer.md).
