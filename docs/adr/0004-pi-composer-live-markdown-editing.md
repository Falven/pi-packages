# Live Markdown editing

`pi-composer` renders supported Markdown inside the editable draft, with a source view for direct syntax editing. Deletion operates on the underlying Markdown through Pi's normal character, word, line, and selection semantics, including hidden syntax, and the existing Markdown parser determines the presentation after each edit so formatting remains a view of ordinary text. Both views share caret movement, selection, and undo, honor Pi's hardware-cursor setting, and render recognized link text with Pi's native hyperlinks, converting absolute local file destinations to file URLs; detailed editing rules are recorded in the [specification](../specs/pi-composer.md).
