# Large pastes become readable attachments

`pi-attachments` captures recognized file-path pastes before applying the text-size rule; other decoded text is measured before editor formatting, with pastes of at least 5,000 UTF-16 code units becoming readable attachments. The same per-paste rule applies across paste routes, with Paste Inline bypassing file-path recognition and the text cutoff, and Attach Text explicitly capturing text, as described in the [specification](../specs/pi-attachments.md). Inline text retains the native editor's tab expansion and LF normalization when that editor is active; `pi-composer` preserves tabs, and attachment snapshots preserve captured bytes.
