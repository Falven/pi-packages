# Large pastes become readable attachments

`pi-attachments` captures recognized file-path pastes before applying the text-size rule; other decoded text is measured before editor formatting, with pastes of at least 5,000 UTF-16 code units becoming readable attachments. The same per-paste rule applies across paste routes. Create from text… captures literal entered text, including strings that look like file paths; Restore Inline converts attached text back to editable draft contents while preserving its retained file. No separate Paste Inline action or command is retained. Inline text retains the native editor's tab expansion and LF normalization when that editor is active; `pi-composer` preserves tabs, and attachment snapshots preserve captured bytes.
