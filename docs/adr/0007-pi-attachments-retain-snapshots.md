# Retain attachment snapshots

`pi-attachments` preserves the contents captured when an attachment is added and keeps existing snapshot paths and recovery records readable, while file references identify current source files. Generated image filenames include their format extension so the system selects the associated application; image labels and previews link to the retained full-resolution file through Pi's native hyperlinks and system handler, including the ability of an external application to save changes to that file. Every snapshot added to a draft remains available for undo histories, saved drafts, submissions, and forks; explicit cleanup reclaims only proven-unused capture or staging data because Pi's public interfaces cannot enumerate every live history or session location.
