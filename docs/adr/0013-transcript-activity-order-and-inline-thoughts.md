# Preserve activity order and inline thought placement

`pi-chat` groups consecutive top-level tool calls across assistant messages, stopping at visible non-tool items or explicit boundaries. Pi's native `hideThinkingBlock` removes reasoning rows completely when true; when false, full native thought prose appears inline without its own header, viewport, or disclosure. This preserves Pi's visibility choice and [native content ownership](0012-transcript-preserves-native-content.md) without a new setting or raw-versus-summary distinction.

## Consequences

Omitted reasoning does not split render groups; visible commentary and meaningful boundaries still do. Live, retained, and pre-compaction reasoning follow the same rule. Standalone bold activity headings label Pi's native working indicator in either mode and are omitted from displayed prose; inline emphasis and canonical source remain intact. [Find](0016-search-retained-transcript-content.md) can temporarily reveal its selected hidden occurrence without changing Hide thinking.

Pi exposes requested delivery mode at input submission, but later handlers and expansion can change or consume the input before both queues construct ordinary user messages without a delivery identifier. The [runtime adapter](0022-native-rows-in-an-owned-transcript.md) observes the actual message objects passed to the initial prompt and returned by each queue's drain, recording delivery only when that user message starts and joining it to its persisted entry afterward. [Relationship metadata](0017-native-transcript-relationship-metadata.md) preserves these established boundaries; where historical delivery provenance is missing, only the uncertain agent activity relationships remain expanded, without inventing boundaries or disabling tool disclosures, inline thoughts, or search.
