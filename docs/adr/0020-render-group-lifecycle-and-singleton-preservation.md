# Retain a disclosure for every render group

Every render group keeps its outer disclosure, including a settled group with one finished operation or execution activity item; [consecutive activity still groups across assistant messages](0013-transcript-activity-order-and-inline-thoughts.md). Each operation retains its activity item regardless of streaming updates, while one tool call can produce several activity items. Groups start collapsed, preserve manual expansion through growth and completion, and keep that choice through ordinary failure or cancellation, independently of the [enclosing agent activity](0015-final-response-outside-agent-activity.md). New activity items start collapsed; collapsing and reopening the group preserves existing rows' independent disclosure choices. Headers use `>` when collapsed and `▼` when expanded at the normal terminal font size and line height. Focused headers use Pi's native selection background, with expansion chevrons still visible and no extra arrow. Individual rows follow the [summary-only collapsed state and default expanded activity bodies](0019-tool-renderers-own-tool-presentation.md).
